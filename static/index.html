市政饮用水污染响应

使用 JSON API 创建污染事件、登记水源或管网记录，并完成复检、通知、冲洗、消毒和恢复。

GET  /health
GET  /api/state
POST /api/items
POST /api/items/{id}/sources
POST /api/items/{id}/actions

冲洗消毒后的片区样本 / 实验室排队 / 恢复审批：
POST /api/items/{id}/sampling/register   登记采样时刻与有效期（满员排队，重复提交幂等）
POST /api/items/{id}/sampling/results    补交完成结果（按采样时刻决定是否推翻原结论）
POST /api/items/{id}/sampling/scope      恢复前变更区域范围（现有结果作废，重新取样）
GET  /api/items/{id}/sampling/pending    已达标但未审批的片区（调度员/监管）
POST /api/items/{id}/sampling/approve    审批只对当前样本版本生效，旧记录留档可查
